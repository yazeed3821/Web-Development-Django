# Web Development Project 

## Overview
This repository features a comprehensive web development project. The project consists of two distinct web applications developed using the Django framework, demonstrating a solid understanding of backend logic, database management, and custom frontend styling.

## Features
* **Multi-App Architecture:** Includes two fully functional web applications integrated within a single Django project.
* **Admin Interface:** Configured Django admin panels for seamless data and content management.
* **Dynamic Web Pages:** Multiple interconnected views and templates rendering dynamic data.
* **Custom Styling:** User interfaces designed and styled from scratch using HTML and CSS.
* **Data Management:** Efficient handling of relational data and models through Django's ORM.

## Tech Stack
* **Backend:** Python, Django
* **Frontend:** HTML, CSS
* **Database:** SQLite
